## 3. 准确性与限制

- **源码主体**来自当时真实的 `write`/`edit` 记录，不是凭提示词猜测的文件分组。
- **重建时的最终提交树**与 2026-10-29 当时的工作区逐字节一致（已校验）；脱敏改动已作为后续提交处理。
- **提交时间与作者**为重建值：作者统一使用脱敏占位身份 `<your-name> <you@example.com>`，时间取自各阶段会话结束时间；不是原始 Git 提交元数据。
- 以下内容无法从会话日志中逐字节还原，使用了最终版本：
  - `pnpm-lock.yaml`、`.npmrc` 等包管理器生成文件；
  - `public/` 演示图片、`docs/*.png` 截图等二进制产物；
  - 在 DSH 之外由用户放入或修改的文件（例如新前端组件、部分脚手架文件）。
- 因此早期提交**不一定都能单独安装依赖并构建**；它们用于表达开发阶段和代码演进，最终提交是完整可运行的版本。
